Built for supportive guidance.

This app combines intent and sentiment detection with optional OpenRouter chat responses. Emergency messages stay controlled and safety-first.

Layer 01

Intent and sentiment

The app classifies messages first, so fallback replies stay useful even when the LLM is unavailable.

Layer 02

Optional OpenRouter LLM

When enabled and configured, OpenRouter writes more natural English responses while the app keeps safe fallback replies.

Layer 03

Account storage

Login, theme preference, and recent chat history are persisted in a local JSON file under the data folder.
