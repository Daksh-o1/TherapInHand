About TherapInHand

Designed for supportive, practical responses.

TherapInHand combines keyword-guided response logic, sentiment and intent detection, specialist handling for emotional and physical concerns, and OpenRouter-backed responses for broader prompts.

Flask backend

Routes render the main pages, handle session-aware messaging, and expose history APIs for the chat interface.

Chat storage

SQLite stores message pairs by session so the chat page can restore previous conversation history cleanly.

Frontend flow

The chat UI loads history on entry, sends messages through JSON APIs, and shows loading state while the assistant responds.

Safety behavior

Emergency and fallback flows remain in place, and OpenRouter integration is preserved for unmatched or broader user requests.
